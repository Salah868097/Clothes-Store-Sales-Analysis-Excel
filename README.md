# Clothes Store Sales Excel Project | Dashboard



## Project Overview

This project involves a comprehensive sales analysis for a clothing store, implemented using Microsoft Excel. It features an interactive dashboard designed to provide clear visibility into sales performance and business trends.



## 📊 Key Features & Analysis:

* **Interactive Dashboard:** Built to track daily, weekly, and monthly sales performance.
* 
* **Sales Trends:** Visual representation of sales growth and seasonal patterns.
* 
* **Product Performance:** Analysis of top-selling items and categories.
* 
* **Data Visualization:** Used various charts (Pivot Tables, Slicers, and Dynamic Charts) for better data storytelling.
* 


## 🛠 Tools Used:

* **Microsoft Excel**
* 
* **Pivot Tables & Pivot Charts**
* 
* **Advanced Formulas**
* 
* **Data Cleaning & Preparation**
* 


## 💡 Impact:

The dashboard serves as a decision-making tool for store management, helping them identify high-performing products and optimize inventory based on sales data.
